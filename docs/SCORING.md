# 遗物装配与流派评分

## 当前实现与待改目标

当前网站用流派规则填写的权重为目标词条计分，100／10／1 是必选、偏好、加分的参考值。排除词条每出现一次扣除其规则权重，并使该组合不满足全部条件。先按必选覆盖排序，再比较分数；同一件遗物命中两个不同目标词条时，每一对加 5。装配预览匹配分与完整推荐分不同。这些是**网站评分策略**，不是游戏内数值公式，权重仍待玩家验收。

重复词条的计分设单次权重为 `w`，出现次数为 `n`，用户设置的有效次数上限为 `cap`：

- 可叠加：`w × min(n, cap)`。
- 条件叠加：`n = 0` 时为 0；否则为 `w + 0.7w × (min(n, cap) - 1)`。这个 70% 是网站对有效重复的评分折算，并非游戏内倍率。
- 不可叠加：`n = 0` 时为 0；否则只计 `w`，即使用户把有效次数设得更高也不重复得分。

没有显式设为排除项的负面词条不会自动扣分。具体哪些效果可叠加、哪些仅在不同等级或模式之间叠加，仍需逐项核对数据与游戏样本。当前页面按效果 key 汇总叠加标记；例如 `increasedMaximumHP` 的普通 ID `7000090` 与深夜 ID `6610400` 标记不同，这种同 key 异标记还需要按 ID／模式传入优化器，暂不能据此断言该效果的推荐分已完成验收。

目标是让用户在网站里编辑并保存流派规则，支持导入导出，且能看到每套推荐的命中、缺失、冲突、重复处理和槽位约束。局内词条暂不加入流派规划；候选目标词条只来自已核对的局外遗物词条目录。

## 规则表字段建议

| 字段 | 含义 |
| --- | --- |
| 流派名、角色、说明、规则版本 | 标识一套可复用的规则 |
| 效果 ID／效果键、显示文案 | 精确选择遗物词条，不只依赖模糊文字 |
| 角色限制、遗物模式 | 普通、深夜或任意；与器皿槽位校验分开 |
| 规则类型 | 必选、偏好、加分、排除、互斥组、至少选一组 |
| 权重、上限、可叠加策略 | 可编辑，但默认值和理由要可见 |
| 适用条件与备注 | 例如出击武器、击败特定目标、玩家自定义取舍 |

首个验收样例是用户提出的**复仇者“兽爪蜗”**：普通遗物必须带“出击时，武器祷告改为兽爪”；击败封印监牢囚犯和黑夜入侵者后永久提高攻击力的词条尽量带；标记为不可叠加的词条只计算一次有效收益。效果 ID、中文原文及不可叠加结论必须先在数据目录中核对，不能凭相似文本写死。

## 推荐输出验收

- 不可装入当前槽位、重复使用同一件遗物、违反角色或模式限制的组合不得进入结果。
- 必选缺失的方案与全部满足的方案分开说明，不能只给一个不透明总分。
- 每个结果展示词条来源遗物、计分明细、互斥／重复折算及未覆盖目标。
- 规则 JSON 有版本号和基本校验；导入旧版本时给出迁移或拒绝原因；浏览器本地保存不应默默覆盖用户规则。
