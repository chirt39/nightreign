# 夜晚Boss与前哨战逐来源核查

2026-11-18，本地游戏 1.3.3.0，regulation 10350000。核查从两个筛选的全部 190 条来源开始，另从夜晚战斗地图反查现有图鉴，找到 5 条原先未列入这两个筛选的来源。

## 核查口径

从 LotResultPlayAreaParam 的第一夜、第二夜及追加首领字段取出 35 种地图模板。将正式 Enemy 部件与同场景初始化事件展开后的具名血条对应，并检查血条的目标实体、实体组、生成器引用及启用条件。区分 NPC 参数编号、地图内单个角色编号和组编号。单个首领可有多个阶段，同名怪物的据点来源和夜晚来源逐条判定。

夜晚战斗中，只有 Boss 血条直接指向的首领本体归「夜晚Boss」。前哨敌人、战中召唤物、随从和坐骑，按用户确认的图鉴口径归「夜晚Boss前哨战」。例如「死诞者们」的组血条指向 47705801，该组骷髅各自没有独立首领血条。王城骑兵 43531110 有独立血条，同名的灵体骑士 43531400 由另一批实体出场，两条来源分别归类。

原生配置和事件证明的是指定战斗中角色的身份。下表的「条件分支」表示启用仍取决于地图模式和事件标志；第一、二夜抽选表没有逐行给出运行时地图模式。按要求保留已关联战斗的角色分类。仅凭新发现的模式 0 分支，不新增出场地点。独立随机突袭按用户指定从图鉴移除，其他来源和原始游戏记录保留。

两个筛选现为 45 条首领来源（44 张卡）和 106 条前哨来源（61 张卡）。34 条撤回中，33 条原属「夜晚Boss」，1 条原属前哨战。其中 26 条来自古龙、熔炉骑士和巨型蚯蚓脸的同名来源，未找到这些编号本身在夜晚首领战挂血条的依据。

蛞蝓 40400010 在蚯蚓脸战斗中有四个实体 48900817 至 48900820。生成器 48902232 使用这四个部件，公共事件 90065100 控制生成器和 48905210 组。蚯蚓脸本体 45803010 的血条挂在 48900800。小型要塞 40400020 和东部地下要塞（大空洞）40400030 均属火 ×1.2 的「蛞蝓」。火 ×0 的「火蛞蝓」由 40401010 在火山口的布置核实，详见[跨地图核查](ENEMY_SMALL_FORT.md#蛞蝓与火蛞蝓)。

77100010 的血条名为「百足恶魔」，原卡误写为另一场战斗的「熔铁恶魔」。本轮分开名称和原有候选图。普通活尸 43000030、43001010、43002020 的前哨归类保留，来源名中的战斗按大树守卫和铃珠猎人场景校正。仅从夜晚模板继承的「大空洞」按既有地点规则一并清理。
