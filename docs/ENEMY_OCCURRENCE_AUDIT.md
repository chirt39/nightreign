## 复核方式

```powershell
python scripts/audit_enemy_occurrence.py `
  --native-dir ../outputs/enemy-full-audit/native `
  --csv-dir ../outputs/nightreign-data-20261109/csv `
  --output ../outputs/enemy-occurrence-20261117/occurrence-audit.json
```

输入包含全量标准命名空间扫描得到的 402 份地图和 278 份事件的解析结果。逐来源输出地图部件类型、具名遭遇、NPC 参数字段引用、事件数值命中及同名属性对照。该脚本只写审计产物，不自动改图鉴或游戏文件。原始资源发现范围和未识别范围见 `outputs/enemy-full-audit/native/README.md`。

验收：公开行数只减少 3，其他来源行及其属性不变；对应地点键删除；生成器不会恢复三条来源；旧 ID 不应错误选中其他怪物。没有因为缺少直接布置就批量移除基础数值、其他形态或整个怪物。
