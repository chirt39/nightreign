# 怪物地点与事件复核（2026-11-18）

范围为上次核查后仍显示「地点与记录差异」的 32 张卡，共 363 行来源、341 个原生 NPC 编号。使用本地游戏版本 1.3.3.0、regulation 10350000。

核对了 402 份地图、123 个生成器和 278 份事件文件。按地图初始化事件与公共事件的参数绑定，区分具体敌人、实体组、占位模型和挂接资产。事件记录表示某个条件分支存在，实际出场还要有可用配置或独立布置依据。

## 夜晚战斗和占位实体

- 罗德尔骑士（4850、4917）、恶兆之子（4928）、小王室幽魂（4930）的夜晚战斗模板均能在 LotResultPlayAreaParam 中找到。各自的地图事件 0 仅在地图模式 0 进入前哨战分支。公共事件 90055000 启用角色和 AI，90055001 读取组内敌人的死亡比例。同模板在 LotResultSmallBaseAndSpot 里的据点模式为 2。每夜首领表能确认模板，但没有直接给出地图模式，不能将模式 2 的据点行用作模式 0 的出场证据。恶兆之子的锻造村另有独立证据。
- 征兆事件 m45_52 的 45520810 至 45520812 读取参数 21500100。公共事件 90035213 启用角色并挂接 AEG596_517 资产。角色模型为 c0100，具名血条另指向 75400010。该链路能证明控制实体被使用，无法识别成玩家可遇见的敌方闪电光球。
