# PC 逐局战果

入口为「日志」中的「出击战绩」。浏览器在本机读取 NR0000.sl2。摘要和累计统计随现有标签页会话恢复，回放数据保存在当前页面内存中，刷新后可重新选择文件。

| 来源 | 字段与用途 |
|---|---|
| USERDATA_10，已核对版本 303 | 相对 cleanData 的 0x54A8 起，每格 1872 字节，共 100 格。记录内 +0 为编号，+4 为 FILETIME 出击开始时间，+12 为持续毫秒。+0x24 为阶段，+0x28 为胜负，+0x2A、+0x2B 为夜王和形态。+0x54 起三个成员位置，每个 592 字节，按实际占用读取。 |
| USERDATA_12 | RSLT v6，逐个读取 DCX/DFLT 槽。明细版本 7、9 按记录编号关联摘要，同时核对配置夜王、地形、时间和参与队员。不同步的摘要仍可查看。 |
| 明细轨迹与事件 | 每个轨迹样本包含毫秒和压缩位置。每条事件保留毫秒、原序、事件类型、参数及可用的平面坐标。地图点另外记录位置、图标和十分之一秒的可见时间边界。 |
| 游戏内显示名称 | UserDispLogParam 的 textId_2 对应简体中文 CL_MenuText。5001 → 146710「受到…救援」，5005 → 146711「救援了…」。击败事件按参数关联 NpcName 等文本。救援事件按实际队伍槽位查找该局玩家名，旧摘要可回退到角色与槽位。 |
| 地图与图标 | 本局保存的 patternId 对应地图配置。底图取自游戏地图图集，地下图使用同套原版 L0_B1 瓦片，按原始瓦片行列放回地表坐标系。地点图标来自 WorldMapPointIconParam 与原生菜单图集，DLC 永夜头像来自 NightBossMenuParam 菜单行 18 的 41848。 |

### 战果一览和装备

| 游戏显示 | 依据 |
|---|---|
| 深度、分数 | 深夜摘要 +0x40 保存本局匹配深度。+1860、+1864 分别保存本人的出击前和结算段位与积分。列表使用结算值，地图角标使用实际匹配深度。满分原始值 10000 按游戏显示为 9999。普通出击省略段位与积分，缺失的结算积分留空。 |
| 本局概要 | 成员 +4 为 UTF-16LE 游戏名。+0x2C、+0x30、+0x34 为圣杯瓶、卢恩和击败数。摘要 +0x2C、+0x30、+0x34、+0x3C 为小队击败敌人、强敌、发现宝物和救援次数。+0x1C 的联机游玩 ID 按 20 位十进制数显示。 |
| 装备 | 每位成员 +0x48 开始有六个武器槽，每槽 80 字节，+0x228、+0x22C 为两个护符槽。按本局记录的物品、战技、法术与附加效果查表。装备目录和图标由 scripts/build_battle_equipment.py 从本作数据生成。 |
| 遗物 | 已匹配的 v9 明细在事件和武器表后按人保存六个遗物槽，每件有编号、三个正面词条及各自对应的负面词条。先与摘要按本局信息匹配，再映射到队伍槽位。v7 明细结束于武器原主表，没有遗物段。 |
| 美术 | 深度 1–5 为 SB_MenuIcon_0 的 MENU_MenuIcon_40203 至 40207。界面背景、标题、阶段条和最终日光晕来自游戏通用菜单图集的 Cmn_bg_01、In_Title_00、In_Cursor_09 和 Cmn_bg_03。统计图标来自 SB_PropertyIcon_0 的 35000、35001、35002、35004、35006、35007。 |

两份 PC 样本的 200 场共 501 个实际参战成员记录。123 个成功配对的明细中，本人的 738 件逐局遗物与同档收藏核对，物品编号及全部正负词条一致。第 501 局结算为深度 5、8750 分。第 190 局由深度 3 升到深度 4、结算 4000 分。第 182 局实际挑战深度 4，本人结算仍为深度 3。
