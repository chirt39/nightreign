## 2026-11-20 全图核查

本轮 1,719 条资料行覆盖 256 张图鉴卡。对照正式数据检查了 811 个地区及形态入口、2,791 个可直接打开的编号与地区组合。新增 154 个正式出场编号均有配图。77 张原生彩色材质模型用于补足缺图或替换错图。508 个同卡、八项倍率相同的来源有明确的代表图映射。档案分别保留 192 项核准绑定和 201 项候选绑定。

缺图来源先核对实际地图部件，再选择实机图或本地游戏模型。例如，持鞭与持杖的蛇人各用自己的模型图，倒挂的艾丝缇使用战斗 AI 462010 的专用动作 `a002_003015.hkx` 和材质覆盖 21600–21603。催眠大螃蟹的沼泽来源 22740020 与大教堂（大空洞）来源 22740030 都使用 c2274 的相同部件、材质与常驻视觉效果，两地共用同一张图。

## 消费契约

全图核查覆盖各地区的代表卡、形态按钮和原始编号详情。优先使用已核准的现成图片。没有对应图片且能确认实际出场的形态，使用该出场编号的角色模型、启用部件、游戏材质和贴图渲染。模型清单记录实际编号、模型编号、地图部件、材质覆盖、姿势和 PNG 校验值。`modelDispMasks` 记录 NpcParam 启用的全部显示位，`renderedMeshMasks` 记录模型中实际存在并参与渲染的编号网格。模型中无编号的常驻网格也参与渲染。

同张卡内的来源可共用已核对的代表图。代表关系存于核准清单的 `representativeBySource`。前端还会核对卡片和八项受伤倍率，再取供图编号和它原有的核准或候选状态。使用其他形态模型作代表时，图片替代文字标为「同倍率代表模型」。格拉狄乌斯的普通分身 75003020 和永夜分身 75003210，分别与配置 0 的本体同属 19005800 组、与配置 10 的本体同属 19015800 组，按配置使用各自的出击菜单头像。

普通体型白金之子的三张单图来自本地游戏模型 c3470。普通、红色长角、银白是用于切换的外观名，材质颜色近似还原。渲染 NPC 分别为 34700000、34700230、34700300，对应图鉴数值记录为 34700000、34700200、34700300。各来源记录按本作 NpcParam 的模型显示掩码和常驻材质分组。

怪物详情按默认数据组的锚点 ID 精确查找图片。优先使用 `public/enemy-image-verified.json` 中的核准记录，再使用 `public/enemy-image-candidates.json` 中同 ID 的候选记录。两份清单均以 `images[id].path` 指向本地图片。候选条目标为 `matchStatus: "candidate"`，玩家可从“资料有误？”反馈更正。每种形态的对应关系写入清单，页面按完整 ID 取图。

两份清单均无可用记录或图片载入失败时，详情标题旁显示“图片待补”。若占位 SVG 本身也载入失败，前端移除失效图像。助手和地图的核准头像来源仍为核准清单。

亚尼姆斯的普通编号 `75210000` 和永夜编号 `75210010` 分别对应地图 `m19_00_00_00` 的 `c7521_9000`、`c7521_9001`。两者共用亚尼姆斯本体的实机截图 `candidate-eldenpedia-44cef6129c675aa3.png`。截图的普通或永夜场次尚未确认，图鉴与计算器选怪页将其标为代表图。格诺斯塔自身的普通和永夜条目分别使用出击菜单图 `41822`、`41842`。

每项记录包含：

- `path`：已存在的站内相对图片路径。
- `sourcePage`、`sourceImage`：既有项用于核对名称、编号和外观的 Wiki 页面及图片 URL；它们不证明仓库内旧素材的来源链。原生菜单图另用下面的游戏资源字段登记来源。
- `assetOrigin`：`legacy-repository` 表示既有资源且历史来源尚未独立追溯；`local-game-menu` 表示从本机游戏菜单图集导出。
- `matchStatus`：既有缩图核对当前详情锚点、来源参考与外观；夜王菜单头像核对首领名称、显式 NPC ID、菜单参数和图集坐标。不能只凭编号或相似文件名标为 `verified`。
- `imageKind`：新增项为 `nightboss-menu-portrait`，详情图的替代文本和悬停提示使用“出击菜单头像”；助手若展示同一 ID 的图片，也使用该说明。不是对应阶段的实景或模型图。
- `sourceGameVersion`、`sourceRegulationVersion`、`sourceResource`、`sourceAtlas`、`sourceLayout`、`sourceRectangle`、`sourceSha256`、`sourceParam`：原生图的游戏版本、包内路径、图集、矩形、PNG 哈希及菜单参数引用。公开清单不包含游戏原始资源包或私人存档。
- `licenseStatus`：`unverified` 表示尚未确认第三方图片的再分发许可；不代表已取得授权。
- `checkedAt`：核对日期。
