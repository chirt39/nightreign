# 全图鉴逐来源复核

核查使用本机游戏 1.3.3.0、regulation 10350000。范围包括普通与灾域来源、夜晚首领及前哨、夜王各阶段和召唤物。每条来源核对八项受伤倍率、七项异常耐受、韧性、四项种族特攻、地点、详情页、计算目标与配图。同一张卡中的多个来源分别核对。

全量核对了 3,016 个原生 NPC 编号和 277 张含角色布置的地图。图鉴补入 154 个实战来源，现有 256 张卡、1,719 条来源。原有来源补上 81 项地点，撤下 57 项误标和 11 项证据不足的旧地点。38 条既有来源共修正 52 个异常耐受值。另校正 21300520 的八项倍率，并为祖灵 46700020 补齐四项原生种族判定。生成数据逐行对照与计算目标八项倍率检查均无差异。

共有 31 个编号能确认实战，中文名称仍待辨认，原始编号和地点保存在[待辨认清单](ENEMY_LOCATION_PENDING.csv)。另外 3 个对象的独立战斗身份尚无定论，其中包括利普拉生成的两种炼金生物。训练、剧情、机关、召唤、未抽取配置和其他来源的具体判定见[原生编号覆盖表](ENEMY_NATIVE_PLACEMENT_COVERAGE.csv)。

## 出场、数值与配图依据

| 项目 | 判定依据 |
| --- | --- |
| 出现地点 | 可抽取的据点配置与 Variation、MSB 中的正式敌人及启用条件。事件中的血条指向、阶段切换和骑乘关系用于区分本体、成员与随从。另行标注已核实同型的地点与尚待确认的触发条件。[地图与事件核查](ENEMY_MAP_EVENT_REVIEW.md) |
| 八项受伤倍率 | 按来源读取 NpcParam，再应用该形态实际生效的常驻效果或已证实的阶段效果。结晶人显示破壳后数值，诺克斯剑士显示落马后的形态，史柴格斯第二条血条单独应用 60546。 |
| 七项异常耐受 | 分别核对基础阈值和 32 个常驻效果位。基础值 999 或实际生效的异常禁用标记显示免疫。沼泽巨型鼠依既定展示约定显示催眠 84，地点备注明确该场免疫。 |
| 韧性和种族 | 韧性取出场编号的 superArmorDurability，小恶魔按约定统一显示 30。虚空、死诞、古龙、普通龙分别核对 isWeakA 至 isWeakD 的原生值。 |
| 计算目标 | 来源编号与图鉴行索引共同定位所选记录。按钮选中的完整八项倍率与该记录逐项对照，包括同编号的不同图鉴行。 |
| 配图 | 优先采用对应实机图片或游戏头像；共图核对卡片、分型与外观依据。缺图的已确认实体使用游戏角色模型、显示部件、武器及彩色材质渲染。逐图记录见[配图依据](ENEMY_IMAGES.md)。 |

玩家提供的参考图有 93 行。按图中表头逐项对照，特别区分打击和斩击、中毒和出血。参考图中的一行可能概括多个体型或场次，逐行清单列出实际采用的来源编号与有差异的字段。

其中 85 行与至少一个已核对象逐项相符（含训练场人偶），8 行与对应战斗记录仍有字段差异。例如英雄石像鬼的实战韧性为 95，参考图为 110。玩家能在图鉴中查看的常态数值，以相应场次的游戏数据为准。
